🔥 Загрузка данных в Firebase

Обновление базы данными за 25.09.2026 18:30.

⚠️ ВАЖНО перед запуском:
1. Открой Firebase Console → Realtime Database → Rules
2. Поставь временно ".read": true, ".write": true → Publish
3. Только потом жми кнопку ниже
4. После загрузки — верни постоянные правила обратно
📅 Загружает: экономику городов + графики + население + размеры + игроков (баланс/актив/рубины/осколки) + нации + войны
